# M1 数据盘点与实验口径验收

日期：2026-10-09。状态：已完成，可进入 M2。验收范围为现有历史实验的数据盘点、使用口径和缺口登记，不表示模型输入已预处理完成或精度已验证。详细确认历史见 [数据说明](DATA_DESCRIPTION.md)。

## 1. 数据与时间口径

- 11 个测站均参与，按唐乃亥至利津的表序确定上下游；站名作为项目标识，原坐标 CGCS2000。缺失观测仅排除对应站点—年份，零/负年径流为异常，不补零。2019—2023 共 55 条观测均为有效正值。
- 按自然年计算，结果主单位为亿 m³/年。当前 2019—2022 校准，2023 独立验证；以后目标年 Y 使用 Y-4 至 Y-1 校准，目标年观测不得用于选参。当前校准样本 44 条、验证样本 11 条；嵌套站点不视为相互独立。
- 2019—2022 可输出校准期结果，不称为独立验证。2023 每站只有一个验证年份，逐站时间序列 NSE/KGE 不可用；报告逐站误差、跨站 MAE/RMSE/偏差及样本数，不把跨站指标当作多年时间验证。
- 两套土地覆盖按用户约定分别固定使用 Copernicus 2019 和精细分类 2023，覆盖全部五年。精细分类为暂定版本，保留后续更新及年份差异的影响说明。
- CMFD 九个变量 60 个月已初筛，目标流域临时掩膜内未发现缺失及基本范围异常。prec/bcpr 都是候选降水率，不相加。M2 在空间口径可比的范围内，用校准期区域降水表辅助比较；不能用 2023 径流选气象方案，不能把面积不一致强行订正成一致。
- 历史参考蒸散采用本次已下载 TerraClimate PET，读取原始值乘 0.1 得 mm/月，12 个月相加为 mm/年；不再乘天数。两套土地覆盖共享同一气候输入。

## 2. PET 最终盘点

`scripts/inspect_pet.py` 已读取 `PET1901.tif` 至 `PET2312.tif` 共 60 幅。按文件名无缺月、重复月或额外月份，全部为同一 573×249 网格；读取期间文件大小和修改时间稳定。全图未发现非有限值、文件掩膜无效像元或负值，原始值范围 0–2806，对应 0–280.6 mm/月。

以当前边界近似转换至 WGS84，在向四周扩展 100 像元的 PET 网格上做像元中心诊断：流域内 47,045 个中心位于导出范围内，范围外为 0，掩膜未触及扩展网格边缘。这是初筛，不是精确面积交叠或全部测站汇水区覆盖证明；边界基准尚未明确、内流区未人为扣除。

导出代码未主动填零，但 TIFF 未声明 NoData，不能由全有效掩膜反推 GEE 源掩膜全部保留。现有零值保留，M2 继续检查零值空间分布及最终计算区域有效覆盖。月日期依据命名与用户导出代码，TIFF 本身无月份元数据。报告为 `project/cache/inventory/pet_metadata.json` 和 `pet_summary.json`；原始数据未修改，未生成正式年度栅格。

## 3. 实测径流比较方案

主基线保留 AWY 自然产水汇总和测站实测年径流两列，按相同站点—年份直接比较，称为“对实测径流的经验拟合/评价”。参数只在校准期选择；不把这类拟合解释为完整自然过程验证，也不将模型与实测差值全部归于地表分类。

已知人类活动资料只有二级区地表水/地下水供水、耗水及大中型水库年蓄水变化。没有额外引调水、地下水储量或还原径流资料，未知项不能当作零。现有表不能直接生成完整天然径流。

M2/M3 可另建水量收支诊断列：在空间归属和耗水含义明确、避免与模型蒸散重复扣除的前提下，比较 `V_AWY - C - ΔS` 与实测值；其中 C 是可归属且未重复计算的净耗水，ΔS 为年末减年初。该式仅是有限资料诊断，不是已批准的完整天然化算法。不得把供水量和耗水量同时扣除，不把地下水耗水全部等同于当年河道流量损失，不按参考面积比例随意拆分二级区数据至内部测站。无法可靠归属时将诊断项标为不可用，保留所有站点的主基线比较；如使用模型内部耗水功能，外部不得重复扣除。

两套土地覆盖使用完全相同的比较口径、有效样本、参数约束和预算。任何新增修正方案必须在查看验证结果选优之前确定。模型不模拟完整河道调度及地表—地下水交换，参见 [InVEST AWY 官方说明](https://storage.googleapis.com/releases.naturalcapitalproject.org/invest-userguide/latest/en/annual_water_yield.html)。
