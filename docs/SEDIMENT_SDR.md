# InVEST SDR 泥沙计算与水沙联合实验约定

更新：2026-10-19。入口：`scripts/run_sediment.py`；配置：`config/sediment.yaml`。

## 今后的实验要求

从本次开始，所有新的水文模拟实验（地类产品比较、精细/大类比较、CMIP6 情景、地类变化）必须同时提供水和沙结果。运行年度产水/测站径流流程后，执行相应输入组合的 InVEST SDR，并在同一次实验记录中链接两套配置、输入指纹和结果。仅完成水量计算不能标记为完整的水沙实验。

SDR 不使用 AWY 的产水量或率定 Z；两模型共享地类、空间域及情景标识，但不是已经实现的水动力—泥沙耦合模型。只改变水模型参数而未改变 SDR 的 DEM、地类、R、K、C/P、流域或 SDR 参数时，可引用**输入完全一致且已完成**的泥沙结果，无须为每个水量率定候选重复跑 SDR。原有历史结果不追溯改写；旧脚本本身尚未全部自动调用 SDR，此约定是今后执行与验收的要求。

本次入口针对当前 48 类精细图。其他分类图必须另建与其代码相符的 C/P 映射，不能套用精细图编码。精细分类的大类应先建立明确的类别聚合，再对其子类 C/P 按同一参考域面积权重聚合；不能把细类参数原封不动保留而称为大类实验。产品间采用相同来源和取值规则，记录混合类别假设；不能根据测站输沙量反向选择有利参数。

CMIP6 或逐年气候实验应提供与情景/年份匹配的 R，或明确报告“固定 R 的地类效应”。年降水量不等于降雨侵蚀力，不能没有方法依据就用降水比例缩放 R。地类改变后必须重新映射 C，并说明措施情景 P 的假设；本次参考域类别 P 均值是基准参数，不能随意由改图后的像元位置重新估计而混入措施变化。

## 输出的物理含义

SDR 模拟片蚀、细沟侵蚀及其沿坡面到河流的输移。**本地 InVEST 3.20.2 的 `sed_export.tif`、`usle.tif` 单位是吨/(公顷·年)**，栅格求和必须乘像元面积（250 米像元为 6.25 公顷）；官方 `watershed_results_sdr.shp` 已完成面积换算，其 `sed_export`/`usle_tot` 为吨/年，不再乘面积。已核查安装版本 `_generate_report` 源码，并以独立栅格汇总校验。不要套用其他版本“吨/像元/年”的说明。`usle.tif` 为坡面土壤流失，不等于入河泥沙。沿用现有 11 个嵌套测站控制流域进行汇总；各站已经包含其上游，不能再次累加各站结果。模型使用自身 MFD 路由，现有测站流域来自水文流程的 D8 划界，两者边界和连通性并不保证完全相同，结果属于既定控制区内的坡面入河估计。

测站年输沙量 ≈ 坡面入河泥沙 + 其他侵蚀来沙 − 水库及河道净淤积。沟蚀、河岸侵蚀、滑坡、河床再悬浮、库坝拦沙和调水调沙并未在本次 SDR 中显式模拟；水体 C=0 只表示水面不发生模型中的片蚀/细沟侵蚀，**不表示水库已经拦沙**。不得将 SDR 汇总直接命名为已校正的测站输沙量，也不得用一个实测/模拟比值冒充已识别的库坝拦沙效率。[1]

`输沙量2011-2024.csv` 只做原值参考，不参与率定或优劣排名。**用户已确认单位为亿吨/年**，配置为 `observation_unit: 100million_t/yr`，换算为吨/年时乘 10⁸。程序也支持 `t/yr`、`10000_t/yr` 和未确认的 `unknown`，未知单位不猜测换算。零输沙量保留为有效观测，缺测不补零。潼关、小浪底、艾山没有现成控制流域，明确列为未匹配，不能借用三门峡或其他站替代。

## 数据与参数

- R：`data/Soil/R-factor1991-2020.tif`。按输入命名解释为 1991—2020 年均侵蚀力，单位约定 MJ·mm/(ha·h·年)。其原始产品文献尚未提供，记录为用户提供数据及单位约定，不能据文件名宣称已核验原始产品。本次不是逐年 2011—2024 模拟。
- K：`data/Soil/epic-k-factor.tif`，用户确认已乘过 0.1317 转为公制；所有读取、重投影和传入 InVEST 的倍率都为 **1.0**。程序拒绝再次配置 0.1317。原始产品文献待补。
- C：两个 `nature_table_*_c_factor.csv` 与 Li 等（2023）的表 2、表 3 对应。[2] 表 2 按作物语义映射到当前图例；程序同时核对代码和完整末级类名，旧图编码不能悄悄复用。玉米小麦两季的 C=0.29 是缺少季节侵蚀力权重时的等权先验，不是当地实测的年度轮作 C。未知耕地使用“Other farm crops”代理。表 3 非耕地范围取算术中值（林地 0.00155、草灌/稀疏林 0.08、稀疏植被/裸地 0.3）；原论文结合 NDVI 的方法未完整复现，不能把中值说成论文推荐的固定值。保留上下界以供敏感性试验。
- C 缺乏直接依据的类别单列假设：湿地草本和城市绿地暂用草本代理；完整温室屋面、居住地不透水面、水体、冰雪取 C=0。居住地假设不覆盖施工裸土，温室假设不覆盖屋间裸地。表 3 的 `No data` 不能自动变成零。
- P：`data/LCLU/P_300.tif` 重投影后，在当前精细图与测站流域联合域内逐类别计算等面积均值，形成 `usle_p`。不是把栅格文件直接当作 SDR 的 P 输入，也不是把原产品地类编码当作当前地类编码。实际 P 值在 0—1；保留 0，拒绝超范围；缺测政策为 P=1 并单列数量，本次域内无 P 缺测。该转换丢失类别内空间差异，类均值 P 与完整空间 P 不保证得到相同输沙量。文件名与论文配套 P 产品一致，但缺少下载记录，不能仅凭文件名确认版本。[2]

SDR 初始参数为 MFD、汇流阈值 1000 个 250 米像元（约 62.5 km²）、k=2、IC0=0.5、SDRmax=0.8、最大 L=122。这些是未率定的基准选择，汇流阈值尤其需要结合实际河网检验，不能宣称已适用于黄河全流域。[1] 250 米网格提高运行效率，但会平滑坡度和细小地貌，绝对侵蚀量有尺度不确定性。

## 空间处理、缺测和性能

沿用水模型的 250 米 Albers 等面积网格和最新精细分类；DEM 使用未刻蚀河道的已对齐高程，避免人工河槽加深放大 LS 坡度。官方 SDR 自行填洼、计算坡度和 MFD 汇流。不额外把湖库设为人工排水栅格。

R、K、P 使用 GDAL average 重投影，不施加单位缩放；分类图使用现有最近邻对齐结果。连续因子重采样不增加原数据的真实分辨率。输入覆盖按现有流域栅格逐块检查。K 缺测在 C=0 表面以 0 补齐；仍会侵蚀的地类采用最近有效 K 值填补，距离上限 10 km，超过即报错。该补值是明确的空间先验，不能当成实测土壤。仅修改缓存副本，原始数据不变。

本次预处理共 12,113,281 个流域像元：R/P 完整；K 缺测 117,461 个，其中 86,347 个位于 C=0 地类，31,114 个使用邻近 K（约 0.257% 的模型面积，1,944.625 km²），实际最远 2,358.50 m。完整统计写入 `manifest.json`。

输入对齐使用两个并行 GDAL 任务，官方 SDR 使用两个 TaskGraph 工作进程；每进程数值线程限制为 1，主进程 GDAL 缓存 256 MiB。栅格统计按块处理，K 最近邻距离计算只在首次构建对应缓存时进行。缓存以源文件 SHA256、网格和处理参数区分，禁止跨图例误用。每次运行独立存放设置、参数表、输入指纹、日志和成功/失败状态。

## 执行和交付

在项目 Python/GDAL 环境执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run.ps1 python scripts/run_sediment.py
```

仅检查和准备输入可添加 `--prepare-only`。输出目录：`experiments/sediment/<UTC时间戳>/`。

恢复或复核已运行的计算可添加 `--resume-run experiments/sediment/<UTC时间戳>`；要求模型设置和源文件指纹一致，只有实测单位的确认允许单独更新，并留下记录。官方 TaskGraph 缓存复用已完成任务。

- `biophysical_table.csv`：48 类 C/P、文献表号、假设、类别像元数与 P 覆盖。
- `manifest.json`、`invest_args.json`、`settings.json`：数据指纹、缺测处理、版本和官方模型参数。
- `invest_sdr/`：官方泥沙输出、栅格和流域汇总。
- `station_sediment.csv`：现有 11 站控制区内的年均坡面入河泥沙及坡面侵蚀量。
- `observations_reference.csv`：10 个实测站的原始年序列、单位状态、未匹配站说明。
- `summary.json`：仅模型和汇总成功后写入；失败记录在 `failure.json`。

## 首次执行结果与验证

已完成 [20261019T062929_361071Z 结果报告](../experiments/sediment/20261019T062929_361071Z/report.md)，[11 站结果 CSV](../experiments/sediment/20261019T062929_361071Z/station_sediment.csv) 和 [实测参考表](../experiments/sediment/20261019T062929_361071Z/observations_reference.csv)。利津控制区坡面入河泥沙为 **1.75896775 亿吨/年**，坡面土壤流失为 **10.826473 亿吨/年**；这些是未率定、当前精细图和多年平均 R 条件下的初始估计。

全域 `sed_export` 有 426,864 个空值，其中 404,469 个是官方模型按设计不计算坡面侵蚀的河流像元；剩余 22,395 个非河流像元没有有效输移结果，约 1,399.69 km²。非河流区覆盖率为 99.8087%；未连通部分不补零，统计结果是有效模型域的汇总。其他站的覆盖率与缺失数量均在 CSV 中。MFD 河网、河道阈值和地形尺度仍需后续独立检验。

官方首次计算约数分钟完成；后续恢复复核复用了 TaskGraph，`summary.json` 的 `elapsed_seconds` 是该次恢复调用耗时，不代表首次完整模型耗时。日志保留初次汇总时输出格式路径不匹配的异常；已按 3.20.2 的 Shapefile 输出修正，历史异常存为 `previous_failure.json`，当前成功状态见 `summary.json`。

验证包括 Ruff、5 项针对性测试（C 语义映射与缺值、P 加权和零值、K 防重复换算、实测零值及单位、3.20.2 栅格公顷换算与河流排除）、官方输入验证和全流域实算。独立分区栅格汇总与官方矢量总量按相对误差 10⁻⁵ 检查通过；细小差异来自汇总浮点精度。
