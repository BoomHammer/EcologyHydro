**共同结构和覆盖：**

- 格式为 NetCDF4；主变量均为 `float32`，维度顺序为 `(time, lat, lon)`，形状为 `(888, 400, 700)`。
- `frequency=mon`，各文件标题均为 Monthly mean，时间覆盖 1951-01 至 2024-12，共 888 个时次。
- `calendar=standard`，时间单位为 `hours since 1900-01-01 00:00:0.0`。时间轴严格递增，2019—2023 每年 12 个月，共 60 个月，无重复月份或缺月；8 个文件目标时段的时间戳一致。
- 时间标签位于月中，例如 2019-01-16 10:30:00；文件没有 `time_bnds` 或 `cell_methods`。依据月频率和 Monthly mean 标题按所属月份解释，不把相邻月中标签之差直接当作该月长度。
- 经纬度轴在 8 个文件间完全一致，间距约 0.1°，小数差异来自浮点表示。经度中心为 70.05°—139.95°，纬度中心为 15.05°—54.95°；纬度递增。转换为常见北向上栅格时需正确处理行方向。
- 经纬度单位为 `degrees_east/degrees_north`。当前属性未明确给出测地基准，不能直接认定与测站 CGCS2000 完全相同。
- 主变量 `_FillValue` 与 `missing_value` 均约为 `1e20`。本轮没有读取气象数值，尚未检查目标区域的有效覆盖率、缺失比例、异常值或数值范围；月份完整不等于数据值无缺失。

**ET0 概念与准备方向（尚未确定具体算法）：**ET0 是标准参考植被在供水充分条件下的参考蒸散量，由气象条件驱动。土地覆盖类型对应的是模型生物物理表中的 `Kc` 等参数；AWY 使用 `PET = Kc × ET0`，随后计算实际蒸散和产水。实验一的两套土地覆盖应共享同一套 ET0。定义参考 [FAO](https://www.fao.org/4/x0490e/x0490e06.htm) 和 [InVEST AWY 文档](https://storage.googleapis.com/releases.naturalcapitalproject.org/invest/3.19.0/userguide/en/annual_water_yield.html)。
