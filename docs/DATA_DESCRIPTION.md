## 气候

| 数据 | 用途及转换 |
| --- | --- |
| `Climate/Data_forcing_01mo_010deg/` 的 CMFD V0200 月数据 | 历史工程基线及候选；`prec/bcpr` 月均通量乘当月实际秒数，年和为 mm，二者不相加 |
| `Climate/TerraClimate_PET/` 的 GEE 月 TIFF | 历史 PET，2019—2023 共 60 个月完整；原值乘 0.1 **一次**再求年和，不再乘天数 |
| 提供方 TerraClimate V1.1 `ppt/pet` NetCDF | 当前成对气候；按文件元数据自动解码一次，再年度汇总 |

CMFD 原始覆盖 1951—2024：temp 为 K、pres 为 Pa、rhum 为 %、shum 为 kg/kg、wind 为 m/s、srad/lrad 为向下辐射 W/m²。风速高度未明确，向下辐射不是净辐射；历史近似 ET0 不等同于完整 FAO-56 输入。

本地 GEE 导出未预乘 0.1，未发现重复缩放。PET 是参考蒸散，AET 是实际蒸散，不能互换。旧 TIFF 缺少可核实小版本信息，不假定与新下载 V1.1 相同。

当前提供方文件、URL、SHA256 及转换结果分别保存于 `project/repairs/climate_reference_full/`（训练）和 `project/repairs/climate_reference_full_holdout/`（2023）。按开发年六个代理区的降水相对 RMSE 选源，未用测试年或径流挑气候，见 [本轮结果](MAJOR_BIAS_CALIBRATION.md)。MOD16A2GF 暂未使用。
