# 精细分类：目标导向的年际储留与区间净损失联合率定

更新：2026-10-12。此方法服务于 `TWO_ACCURACY_GOALS.md` 的表一和表二。
2022—2024 年观测直接用于率定和候选选择，属于**开发期目标拟合**。
它不构成独立验证，也不能证明精细分类数据本身优于另外三个产品。

## 诊断与方法选择

旧入口仍按训练期 CV 选型，且只比较基线和已排除的上游 Z=60 边界方向，
与当前文档目标不一致。本轮先用已有全像元产水缓存分解七站累计残差与区间残差。
2023 年上游贵得高估 22.130 亿 m³，兰州高估 29.426 亿 m³；
三门峡—花园口区间又增加 21.206 亿 m³，花园口—利津增加 14.444 亿 m³。
2024 年上游则低估，不能通过统一增加上游蒸散简单修正。

先检验已有过程的联合作用：固定所有逐像元 AWY 参数及输入，调整现有七区的
年际储留系数和一个兰州—头道拐（LTG）净损失参数。没有新增积雪、灌溉或耗水过程，
也没有以独立测量的名义引入新的水量。所有站年由同一个完整空间参数向量模拟，
每个区间的参数跨年不变，不拼接不同候选的预测。

保留原边界：储留系数 `r ∈ [0, 0.5]`，净损失 `L ∈ [0, 100]` 亿 m³/年。
这些是沿用的探索性有效参数边界，不是新验证的物理先验。

## 水量账户

先将逐像元产水累积值差分成七个本地区间产水量 `N[t,j]`。
各区只储留本地区间产水，不对同一上游水量逐站重复执行储留：

```text
S[0,j] = r[j] / (1-r[j]) * N[0,j]  （首年平衡初始化）
D[t,j] = (1-r[j]) * (S[t,j] + N[t,j])
S[t+1,j] = r[j] * (S[t,j] + N[t,j])
N[t,j] = D[t,j] + ΔS[t,j]
Q[t,k] = Σ(j≤k) (D[t,j] - C[t,j] - R[t,j] - L[j])
```

`C` 为原公报地表耗水，`R` 为原实测水库蓄变；只有 `L[2]=L`，其他区为零。
因此 LTG 损失仅产生一次，其影响随干流水量传递到下游五站，不是五次耗水。
`S` 是原模型中的概念性集水区储留，不能再次解释为已经包含在 `R` 中的水库蓄变。
记录每区每年的产水、输送、储留、已知耗水、水库蓄变、净损失和水量闭合残差。

`L` 仍是未被现有账户解释的**有效净损失残差项**，会吸收输入误差及未表示的过程。
它既不是公报耗水的再次分配，也不是实测渗漏量；数值增大不能证实某个物理机制。
本轮不改变像元 ET，也不另加公报总耗水或灌溉，避免新引入重复扣水。
现有 AWY—地表耗水账户的物理分离仍依赖原协议，代数闭合并不能证明所有过程都已正确识别。

## 候选、选择及完整记录

比较基线、仅储留、仅净损失，以及联合率定的四种训练期权重：0、0.05、0.25、1。
目标函数是三年站点相对误差平方均值，加指定权重乘历史训练期相对误差平方均值。
每个时期内部等权；训练期权重不随年数隐式改变。每个候选有三组初值，
保留各初值收敛状态、次数和目标值。

使用全精度指标排序：

1. 两项硬目标未通过的数量；
2. 表一距离 4/4 的差额；
3. 表二距离 9/21 的差额（多出的胜出数不作为强迫继续拟合的奖励）；
4. 2023 年七站相对 RMSE；
5. 三年整体相对 RMSE。

CV 和互换诊断不否决达到目标的候选。所有候选的参数、21 个预测及评价结果保留；
全时期的站年改善与退化均写入 `all_year_changes.csv`。

训练期诊断重新加载原三个折各自的产水参数，在各折可用训练年份内重估储留/净损失，
其拟合时段截断到最后训练年；被留出的观测不进入目标函数。
折内预测按时间顺序传递状态，尤其保留严格前推折。
这只能诊断同一率定方法在历史数据上的稳定性，**不能验证使用三年目标观测得到的最终参数**。
最终参数回算历史年份的误差明确称作回代误差，不冒充 CV。

## 计算、复核与复现

搜索只操作 14×7 的年产水数组，避免每个优化步重新扫描栅格。
选中方案用 InVEST 官方 `fractp_op` 对 2011—2024 全像元分块复算，
沿用两个进程、每进程一个计算线程和 24 GiB 内存上限。
逐年产水必须与未改变参数的原全像元缓存一致，再执行新的储留与水量账户。
高分辨率抽样与全像元结果还需满足原 1% 观测量误差容限。

互换表更新精细参数来源整行，其他三种参数来源不变。
由于本轮像元参数不变，其他地类输入在精细来源下的逐年产水可直接复用原全像元缓存，
但输送/储留必须按新参数重新计算，并重新核对抽样积分误差。
原互换矩阵其他三行完整保留，因此交付的是本轮 4×4 矩阵。
输入文件和冻结对照用 SHA256 校验；不覆盖原实验。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run.ps1 python scripts/experiment_fine_2023_focus.py
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run.ps1 python scripts/report_fine_focus.py experiments/fine_2023_focus/<运行目录>
```
