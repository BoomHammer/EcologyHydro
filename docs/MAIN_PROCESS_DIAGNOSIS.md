# 主要误差定位：上游来水与年际水量过程

日期：2026-10-10。承接 [长序列验证](LONG_RECORD_VALIDATION.md)。按用户要求聚焦主要矛盾，不继续寻找更细分区或微调约束。本轮未率定新参数，未改变七区结构、生产参数或原始数据，未生成新 2023 预测。

**主要结论：应优先处理兰州以上、尤其贵得以上的年际产水响应。下游误差相当一部分是上游传递而来；简单删除耗水、添加外部储量、按统计表缩放降水或直接替换为外部月模型，都没有构成可靠解决方案。** 尚不能在现有资料下把剩余误差唯一归因于降水、蒸散或地下水记忆。

## 1. 先定位误差来自哪里

使用上一轮七区模型，参数固定为 2013—2017 年拟合值，保留官方内核全像元的 2019—2022 结果。2019 年精细模型的误差为：

| 测站 | 模拟减实测，亿 m³ | 相邻区间新增误差，亿 m³ |
| --- | ---: | ---: |
| 贵得 | -71.17 | -71.17 |
| 兰州 | -100.73 | -29.56 |
| 头道拐 | -82.01 | +18.72 |
| 龙门 | -100.84 | -18.83 |
| 三门峡 | -89.98 | +10.86 |
| 花园口 | -107.60 | -17.62 |
| 利津 | -93.43 | +14.17 |

到兰州时已形成约 101 亿 m³ 的缺口，往下游误差围绕这一量级波动。这与“每个下游区间都少产了约 100 亿 m³”不同：累计测站重复包含同一上游来水。

进一步固定全部下游参数，仅以同年上游实测 Q 替代对应模拟 Q：

`下游条件预测 = 原下游预测 + 上游实测 - 原上游预测`。

该诊断回答“如果上游来水已知，下游还剩多少误差”，**不是独立全流域预测，也不是把实测塞进最终模型后的精度提升**。

| 2019—2022 兰州以下五站 | 精细相对 RMSE | Copernicus 相对 RMSE |
| --- | ---: | ---: |
| 原七区模型 | 14.46% | 15.75% |
| 仅贵得来水已知 | 8.12% | 8.37% |
| 兰州来水已知 | 5.82% | 7.15% |

换成 2022 行业耗水账户，兰州来水已知时为 6.87%／8.67%；扩展训练方案两版账户下为精细 6.61%—6.68%、Copernicus 6.86%—7.55%。上游值得优先研究的方向不依赖单一地类或单一账户。此结果不表示下游所有局地过程正确，局地误差仍可相互抵消。

## 2. 耗水重复扣除不能解释主要上游缺口

2019 年贵得以上的已知地表耗水仅 1.09 亿 m³；到兰州累计为 21.09 亿 m³。保持参数不变，即使极端地取消全部地表耗水扣除，贵得约 71.17、兰州约 100.73 亿 m³ 的原缺口也只能分别减少 1.09、21.09 亿 m³。因此上游主要误差不是简单删除耗水就能解决的。

这只约束固定参数算子的直接作用，不排除全流域率定时下游账户通过共同 Kc 影响上游参数。也不证明现有耗水扣除正确：灌溉蒸散是否已经计入 AET，仍需按过程区分。[InVEST 对季节灌溉、耗水与模型率定的限制](https://storage.googleapis.com/releases.naturalcapitalproject.org/invest-userguide/latest/en/annual_water_yield.html)

已知水库蓄变在基准中已经扣除，2019 贵得以上为 -3.78、兰州累计 -6.44 亿 m³，不应再作为“新增蓄水释放”重复加回。

## 3. 上游月尺度诊断：储量不是全部答案

补取 TerraClimate V1.1 的月 AET、Q、土壤水和雪水状态，仅覆盖兰州以上区域；期间为 2012 年 12 月至 2022 年 12 月。2012 年 12 月只提供初始状态，未补造 2012 实测水文。P/PET 复用已有同版本月文件。

以修正后汇水区的每个 250 m 等积像元中心作双线性取值，再按真实像元面积汇总；计算贵得以上和贵得—兰州两个非重叠区域，累计得到贵得、兰州。没有为每个月写出全流域高分辨率栅格。两套地类共用这个外部过程诊断，不将其当成地类模型比较结果。

外部月模型使用静态参考地表，并非独立蒸散／储量观测；V1.1 还包含月间径流滞蓄。[TerraClimate 提供方的方法及局限](https://www.climatologylab.org/terraclimate.html)

2019 年结果：

| 水量项，亿 m³ | 贵得以上 | 兰州以上累计 |
| --- | ---: | ---: |
| 精细七区原预测 | 243.03 | 376.57 |
| 实测径流 | 314.20 | 477.30 |
| 外部土壤＋积雪释放 | 17.20 | 27.91 |
| 只加上述释放后的条件预测 | 260.23 | 404.48 |
| 外部月模型 Q 再扣同样管理账户 | 213.34 | 245.28 |

外部土壤／积雪释放量约为原缺口的 24%／28%，不能单独闭合缺口。这里比较的是外部模型给出的量级，不是量测证明真实缺口有对应百分比由该过程造成。

直接使用外部月 Q 反而低估更多。原因可由同一降水下的代数分解看出：2019 外部 AET 比精细 AWY 高约 46.17 亿 m³（贵得）和 158.84 亿 m³（兰州累计），超过储量释放的作用。较细时间步长本身不保证更准，蒸散与储量必须一起检验。

在 2019—2022 四年中，外部月模型的条件径流相对 RMSE 为贵得 24.97%、兰州 44.41%；精细 AWY 分别为 11.84%、11.28%。此处外部模型未做本流域率定，AWY 已按早期实测率定，因此不是公平的模型优劣竞赛，结果仅足以否定“直接用外部 Q 替代即可解决”的做法。

固定 AWY 参数、只拼接外部土壤／雪水蓄变后，精细贵得／兰州相对 RMSE 为 10.06%／8.11%，但这属于查看后期误差后的过程敏感性诊断，未同时检验完整流域，也没有与新增储量一致的 AET 方程，**不作为新生产方案验收**。

![上游年际过程诊断](../project/diagnostics/headwater_balance_v1/headwater_process.png)

外部资料内部也需要保留闭合残差：累计年度 `P-AET-Q-Δsoil-Δsnow-Δcarry` 的最大绝对值约 0.024 亿 m³，但单月局地区间残差最大约 5.98 亿 m³。`Δcarry` 使用提供方 0.5 滞蓄系数下的月 Q 状态差作诊断，不能据年度接近闭合宣称所有月过程严格闭合。残差全部保存，本轮不追查其季节细节或据其修正径流。

2019 年上游融雪与降水共同作用也有卫星分析支持，但该报道不能验证本项目的年度水量分摊。[中国天气网／国家卫星气象中心遥感资料，2019-07-17](https://news.weather.com.cn/2019/07/3216437.shtml)

## 4. 降水差异能解释多少

保留早期参数，将两个上游代理区的 P 分别缩放到当年统计区折算的平均降水深度；PET、地类和其他参数不变。此对照不使用径流挑系数，但两种边界不一致，故**不是已核验的降水订正**。为节省计算，使用原确定性分层积分计算固定参数的产水差，再加到原全像元预测；该情景结果本身不是全像元正式验证。

精细模型：

| 年份／站 | 原预测 | 降水对照预测 | 再拼接外部土壤／雪水蓄变 | 实测 |
| --- | ---: | ---: | ---: | ---: |
| 2019 贵得 | 243.03 | 263.90 | 281.10 | 314.20 |
| 2019 兰州 | 376.57 | 513.18 | 541.09 | 477.30 |
| 2020 贵得 | 312.54 | 277.43 | 294.81 | 330.60 |
| 2021 贵得 | 234.92 | 187.89 | 186.40 | 230.20 |
| 2022 贵得 | 203.18 | 135.27 | 148.31 | 195.90 |

单位均为亿 m³。2019 贵得以上 P 只增加约 3.30%，产水增加约 20.87 亿 m³，仍不足以闭合 71.17 亿 m³ 缺口。贵得—兰州局地 P 则增加约 32.95%，使兰州累计产水增加约 136.61 亿 m³并过冲。它说明该段降水空间／统计口径差异具有足够大的影响，值得独立核验；并不支持直接套用统计系数。

该方案对贵得 2020—2022 均明显变差，两套地类逐年结果全部保留在 `precipitation_sensitivity.csv`。没有根据 2019 改善挑系数，也没有把统计降水换入主输入。前轮全流域降水重建跨年表现不佳，与本轮“不直接替换”的判断一致。

## 5. 现在能够确定和不能确定的事

- 可以确定：累计站误差不能当作各区间独立误差；兰州以上是当前优先区域。贵得以上难以复现 2019 丰水响应是两套地类共有的问题。
- 可以确定：已知耗水的直接量级不足；已有外部土壤／雪水蓄变也不足；简单拼接各项会出现抵消和过冲。当前资料尚未支持一个可靠的新修正公式。
- 尚不能确定：剩余贵得缺口是蒸散估计、降水时序与空间偏差、地下水／湖泊记忆、未记账储量或几项共同造成。外部 AET 与 AWY 不一致不能证明哪一个是真值。
- 尚不能确定：精细分类是否具有稳定优势。两套地类在上游表现接近且共同失配，继续调土地覆盖相关参数可能掩盖共同过程问题。

**后续只保留一个主线：贵得以上建立最小的月尺度降水—蒸散—储量连续计算试点，优先检验不同丰枯年份的响应。** 作物／植被和土壤仍使用现有两套地类及同样参数预算；2018 缺管理账可以连续推进气象状态，但不能补造管理径流目标。蒸散与储量必须在同一守恒框架内计算，不能只取外部模型某个效果好的分量。

试点是对 AWY 年尺度适用性的过程检验，应单列为模型扩展；不能称为未经修改的官方 AWY。兰州以下暂不增加分区或过程参数，贵得—兰州的降水差异作为明确的输入不确定性保留。对已查看的 2019—2022 结果不再声称全新盲测；仍不使用反复检验过的 2023 来挑参数。

## 6. 计算、产物和复核

上游月诊断含下载约 176 秒；只有四份小范围月序列 NetCDF，共约 63 MB，下载双线程、NetCDF 顺序解码，栅格分块处理，复用两个原生网格的空间权重。月 P 累加汇总与既有年度栅格汇总的最大相对差为 8.35×10⁻¹⁰。没有修改原栅格或模型代码。

主要产物为 [headwater_balance_v1](../project/diagnostics/headwater_balance_v1/summary.json)：

- `monthly_balance.csv`：两个非重叠区共 240 条月记录；P/PET/AET/Q 为月通量，soil/swe 为月末状态，单位亿 m³。
- `annual_local_balance.csv`、`annual_cumulative_balance.csv`：年度通量、状态差和条件水量；不累加月末储量本身。
- `process_decomposition.csv`：外部月模型与 AWY 的 AET、土壤／雪水、滞蓄及闭合残差差异，保留代数恒等式。
- `headwater_comparison.csv`：仅贵得／兰州的四年条件诊断分数，不混入 2018 或全流域指标。
- `precipitation_sensitivity.csv/json`：固定参数降水情景及指纹；`precipitation_initial/` 保留长字符串格式修正前的初次同数值结果，当前父目录为最终结果。
- PNG/PDF 图、下载 URL／SHA256／变量元数据、`verification.json` 均保留。

新增两项测试验证全部像元面积权重、线性场双线性积分以及贡献像元缺失拒绝；实际产物另核验 27 项来源指纹、240 条月记录和过程分解恒等式。原长序列试验核验、旧冻结核验与 Ruff 检查继续保留。
